## Defect found and fixed

A command run in a project subdirectory could be replayed correctly by `redo`, but exported reports did not tell the recipient where it ran. Reproduced a recorded command passing from `arena/` and failing from the project root when following the exported command alone.

The fix retains project-relative working-directory context for command history, current failures, passing verification, chronology, and reproduction/verification instructions across Markdown, HTML, JSON, and the Explorer. The red-to-green JSON record also identifies its directory. Project-root runs use `.`. Legacy, malformed, or outside-project locations remain unknown; absolute workspace directories are not added to these fields. Historical symlinks are not resolved against the current filesystem. This uses Python's documented [pure path operations](https://docs.python.org/3.11/library/pathlib.html#pathlib.PurePath.relative_to).

Replayed the command successfully using the directory supplied by the fixed export. Regression tests cover different directories, the project root, missing/legacy data, outside-project paths, CLI replay from another directory, all report modes, and inert rendering of malicious directory text. Existing session storage and commands are unchanged; the JSON fields are additive.
